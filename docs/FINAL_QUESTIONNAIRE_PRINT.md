# 阅读理解与智能辅助实验最终问卷（纸笔版）

对应打印文件：[FINAL_QUESTIONNAIRE_PRINT.html](./FINAL_QUESTIONNAIRE_PRINT.html)。本问卷只在同一被试完成三轮任务后填写，一张 A4 纸完成，不再使用“本轮整体体验”问卷。

## 设计原则

- 所有需要勾选的项目已合并为两张表：三轮整体比较表、两种主动辅助方式比较表。
- 全文不出现 C1、C2、C3、EEG、gaze 或 policy 等条件名称；只使用“第一轮、第二轮、第三轮”和“主动方式 A/B”。
- 主动方式 A/B 的后台随机映射由主试在发放前记录，不能让被试看到具体条件名称。
- 没有相关体验时选择“不适用”“没有相关体验”“两种都未出现”或“无法判断”，不强迫被试猜测。

## 问卷内容

1. 三轮整体比较：理解帮助、获得所需解释、解释清晰度、与当时阅读情况的匹配度。
2. 主动辅助体验：是否曾被系统主动询问、主动询问时机是否符合需要、是否漏掉帮助需求、是否打断阅读思路。
3. 主动方式比较：准确识别、询问时机、无需要时的误触发、漏掉帮助需求四项。
4. 四道开放题：准确识别经历、错误判断经历、理想触发情境、改进建议。

## 打印设置

用浏览器打开 HTML，选择 A4、纵向、实际大小（100%），关闭页眉页脚后打印。建议打印前预览确认内容完整落在一页内。
