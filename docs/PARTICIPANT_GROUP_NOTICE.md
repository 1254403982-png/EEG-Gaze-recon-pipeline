# 被试群公告模板

## 欢迎参加阅读理解与智能辅助研究

感谢报名参加本研究。本实验关注人在阅读材料、理解内容和接受阅读辅助时的体验。实验过程中请按照页面提示阅读材料并回答问题，遇到不确定的内容按自己的真实感受操作即可，没有“标准的操作方式”。

请为实验预留约 3 小时，具体时间以主试现场安排为准。实验开始前会有简短说明、设备佩戴和校准；实验结束后需要完成简短问卷。

## 参加前准备

1. **洗头安排**：请提前一天洗头；实验当天不要洗头，也不要在实验前几个小时洗头。实验需要在头皮上使用脑电膏，保留头皮的天然皮脂有助于保证电极接触和信号质量。
2. **不使用头发产品**：实验前不要使用发胶、发蜡、干洗喷雾、护发精、定型喷雾或其他头发产品。
3. **预留时间并避免匆忙**：请提前安排好行程，为实验预留 3 小时，尽量避免因赶时而过度出汗，以免影响脑电信号和佩戴舒适度。
4. **保持正常状态**：实验前尽量保证睡眠，按平时习惯进食和饮水。若当天身体不适、头皮有伤口、近期做过头发护理或无法配合佩戴设备，请提前告知主试。
5. **减少头部和面部遮挡**：实验时请尽量不要佩戴帽子、厚重头饰或会遮挡眼部的饰品；眼镜佩戴者请提前告诉主试，以便安排 Tobii 眼动眼镜。

## 设备与实验配合

- **脑电设备**：主试会佩戴脑电帽并使用导电膏连接头皮。请保持放松，尽量减少频繁大幅度点头、转头、咬牙和说话；需要调整时直接告诉主试，不要自行拉动电极或连接线。实验结束后如果头发上有少量脑电膏，可在主试建议下戴帽遮盖。
- **Tobii 眼动眼镜**：眼动眼镜的摄像头会记录视线相关画面并进行校准。请自然阅读，尽量让头部保持舒适稳定；不要触碰镜片前方的摄像头。校准不舒服或看不清时，请立即告诉主试。
- **阅读与提问**：请按页面顺序阅读，不需要为了触发系统而刻意移动眼睛或头部。若页面出现 AI 询问，请先按“需要帮助”或“不需要”作答；正常情况下仍可以复制材料内容并选择解释方式后发送问题。
- **答题与问卷**：请根据刚刚阅读的材料独立作答，问卷只需填写真实体验。没有相关体验时按页面提供的“不适用”选项操作。
